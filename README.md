## Combat Skirmish

Counter-Strike 1.6 in your browser: **[combatskirmish.net](https://combatskirmish.net/)**

- Free, no download, no Steam account.
- Joins the same public CS 1.6 community servers as the Steam version: [live server list](https://combatskirmish.net/servers).
- Ranked 5v5 matchmaking, co-op, and bots.
- Works on computers, phones and tablets, with touch controls on touch screens.

It runs Xash3D FWGS, an open-source GoldSrc-compatible engine, compiled to WebAssembly.
